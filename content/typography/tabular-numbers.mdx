Digits can have two kinds of spacing.

**Proportional figures** use the natural width of each shape: `1` is narrow,
while `8` is wide. **Tabular figures** give every digit the same width. Toggle
the demo to see the glyph boxes change.

<TabularNumsDemo />

Use proportional figures when numbers sit inside a sentence. They read more
naturally. Use tabular figures when the position of a digit needs to stay
fixed.

## Changing values

A timer made with proportional figures changes width as it runs. Everything
beside it moves too. Watch the red edge in the demo.

<TabularTimerDemo />

Tabular figures turn every character into a stable slot. The digits change;
the width does not. Use them for clocks, counters, scores, prices, and live
metrics.

## Rows and columns

In a numeric column, equal-width digits create a vertical grid. Repeated
places line up, so differences are easier to scan.

<TabularTableDemo />

Right-align numeric columns as well. Tabular figures align the digits;
right alignment keeps numbers with different lengths anchored to the same
edge.

## In CSS

```css
.timer,
.numeric-column {
  font-variant-numeric: tabular-nums;
}
```

In Tailwind, use `tabular-nums`. Apply it only to the values that need it;
the property inherits, and proportional figures usually look better in body
copy.

The font must include tabular figures for this to work. If `tabular-nums`
makes no visible difference, try another font or inspect its OpenType features
for `tnum`.
