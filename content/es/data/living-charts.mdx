Los datos en tiempo real llegan por pasos. Un servidor envía un número cada segundo, aproximadamente, y el gráfico debe mostrarlo. Si renderizas cada valor en cuanto llega, el gráfico da saltos. Si avanzas hacia él durante unos cientos de milisegundos, parece respirar. Un **gráfico vivo** nunca se teletransporta.

Las dos tarjetas reciben el mismo valor al mismo tiempo, cada segundo y medio. La izquierda lo dibuja de inmediato. La derecha utiliza un tween para pasar del valor anterior al nuevo.

<LivingChartsDemo />

Los datos no han cambiado. La tarjeta derecha simplemente reparte cada cambio a lo largo de `900ms` con una curva ease-out. Así, la mayor parte del movimiento ocurre al principio y el número se asienta suavemente. Si el tween termina antes de que llegue la siguiente actualización, el gráfico sigue siendo fiel a los datos: en cada actualización, ambas tarjetas coinciden.

## El número forma parte del gráfico

Fíjate en el contador sobre la sparkline. Un número que salta de 620 a 790 se interpreta como dos datos. Un número que aumenta progresivamente se interpreta como un cambio, que es lo que representa. Usa `tabular-nums` para que los dígitos no se desplacen lateralmente mientras cambian.

## Listas ordenadas por valor

Cuando los valores en tiempo real cambian de orden, lo interesante es la reordenación. En una lista sin transición, las filas intercambian posiciones entre fotogramas y el lector pierde la pista de cuál es cuál.

<LivingBarsDemo />

Con la animación activada, cada fila se desliza hasta su nueva posición y su barra crece o se encoge en el mismo sitio. El ojo puede seguir cómo GitHub adelanta a X sin volver a leer las etiquetas.

## Uso

El tween es un hook breve. Guarda los últimos valores mostrados en una ref y, con cada nuevo destino, avanza desde ellos hasta los nuevos valores mediante `requestAnimationFrame` y una curva de easing.

export function useTweened(target: number[], duration = 900) {
  const [display, setDisplay] = useState(target);
  const current = useRef(target);

  useEffect(() => {
    const from = current.current;
    const start = performance.now();
    let frame = 0;

    const step = (now: number) => {
      const t = Math.min(1, (now - start) / duration);
      const eased = 1 - Math.pow(1 - t, 3);
      const next = target.map((value, i) => {
        const origin = from[i] ?? value;
        return origin + (value - origin) * eased;
      });
      current.current = next;
      setDisplay(next);
      if (t < 1) frame = requestAnimationFrame(step);
    };

    frame = requestAnimationFrame(step);
    return () => cancelAnimationFrame(frame);
  }, [target, duration]);

  return display;
}

Comprueba dos cosas. Mantén el eje Y fijo en un intervalo conocido mientras llegan datos; si no, todo el gráfico cambiará de escala con cada actualización y deshará la calma que acabas de añadir. Y respeta `prefers-reduced-motion`: cuando esté activado, omite el tween y muestra el valor de destino directamente.
