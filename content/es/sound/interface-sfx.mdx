Un sonido de interfaz es una señal, no una banda sonora. Dura unos milisegundos y dice una sola cosa: ha funcionado.

Los **SFX de interfaz** deben corresponderse con la acción que confirman. Un interruptor recibe dos notas alternadas; una tarea completada, un tic breve; un mensaje enviado, un pequeño acorde ascendente; y una eliminación, un pop descendente. Prueba los controles. Utilizan el mismo patch que reproduce este sitio.

<SoundCuesDemo />

Cada sonido va acompañado de algo visible: el interruptor se mueve, el texto se tacha, el botón muestra Enviado o el chip desaparece. El sonido nunca transmite un mensaje por sí solo. Hay quien lo tiene desactivado, quien va en tren y quien simplemente no lo quiere.

## Dónde ayuda el sonido

El sonido se gana su sitio cuando termina una acción y quizá estés mirando hacia otro lado. Enviar, copiar, guardar, una subida larga que termina o un interruptor que has accionado con el teclado. Los errores también son buenos candidatos, siempre que el sonido sea tranquilo y no una alarma estridente.

En casi cualquier otro caso, molesta: escribir, hacer scroll, abrir menús, cambiar de página o cualquier acción que ocurra decenas de veces por minuto. Si una señal puede sonar dos veces en el mismo segundo, no debería existir.

## Mantén el volumen bajo

El error más habitual es el volumen. Una buena señal se sitúa en el límite de la atención. En términos de `@web-kits/audio`, eso significa un gain (ganancia) por capa de entre `0.05` y `0.1`, muy por debajo del valor predeterminado de la librería. Copia el enlace con cada nivel.

<SoundLevelDemo />

El silencio está bien. Un volumen bajo es lo que debería oír la mayoría. Un volumen alto es lo que la gente recordará como el motivo por el que silenció tu aplicación. Si puedes tararear la señal después de oírla una vez, es demasiado fuerte o demasiado larga.

## Hover: un susurro o nada

Hover se activa constantemente, así que un sonido marcado en cada hover convierte una barra lateral en un instrumento de teclado. Recorre la lista con cada opción.

<HoverSoundDemo />

El susurro es una onda sinusoidal con gain `0.01` que sube un cuarto de semitono por elemento. Así, bajar por la lista se parece a deslizar el dedo por un raíl. El tic es el sonido de clic, y en hover resulta agotador. El silencio también es una opción perfectamente válida.

Dos reglas más. Los navegadores mantienen el audio suspendido hasta el primer clic o pulsación de tecla, así que las señales de hover anteriores deben descartarse, no ponerse en cola. Y el control para silenciar debe estar a la vista. Este sitio lo tiene en la cabecera y recuerda la elección.

  },

  try {
    await ensureReady(); // resolves after the first user gesture
    ui.play(name);
  } catch {
    // no audio available, the visual still happens
  }
}
